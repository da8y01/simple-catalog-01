# Simple Catalog

A simple catalog to showcase articles and items; with shopping cart, BlockChain/Web3 capabilities, smart-contracts, auctions, crypto-currency support.

## Quickstart

To launch the application, follow the steps below:

1. Install dependencies:

```
cd simple-catalog-01
yarn install
```

2. Run a local network in a first terminal:

```
yarn chain
```

3. On a second terminal, deploy the test contract:

```
yarn deploy
```

4. On a third terminal, start the app:

```
yarn start
```

Visit the app on: `http://localhost:3000`.
